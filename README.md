# 🚀 Blogify API

A fully-featured RESTful API for a modern blogging platform.  
Built with Node.js, Express, and MongoDB, Blogify supports authentication, post management, file uploads, and payment processing.

---

## 📌 Features

- 🔐 User Authentication (JWT-based)
- 📝 CRUD operations for blog posts
- ☁️ Image uploads via Cloudinary
- 💳 Payment processing with Stripe
- 📦 Order management system
- 📄 Pagination support for posts
- 🔒 Protected routes & authorization

---

## 🛠 Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Authentication:** JWT (JSON Web Tokens)
- **File Storage:** Cloudinary
- **Payments:** Stripe
- **Cloud DB:** MongoDB Atlas

---

## ⚙️ Prerequisites

- Node.js (v16+)
- MongoDB Atlas account
- Cloudinary account
- Stripe account
